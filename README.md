# 学习面板

一个纯静态的单文件学习计划面板，用来每天查看「今天该学什么」并逐条勾选。

## 页面

| 文件 | 内容 |
|---|---|
| `index.html` | 入口页，两个按钮 |
| `今日面板.html` | 当天任务清单、本周进度、全程进度 |
| `进度看板.html` | 27 个月甘特图，六个方向的时间线 |

## 使用

打开网页即可，不需要登录，不需要安装。

勾选状态保存在浏览器本地（`localStorage`），按访问地址隔离——换设备或换域名会看到一份独立的记录。面板右上角有「导出备份 / 导入备份」可以在设备之间搬进度。
